# Publicação do editor

O destino do projeto é [GustavoMissawa/antropologo-rpg-map](https://github.com/GustavoMissawa/antropologo-rpg-map).

- Em **Settings → Pages**, a origem da publicação é **GitHub Actions**.
- O workflow usa `npm ci`, executa `npm test` e publica o diretório `dist`.
- Acompanhe o deploy na aba **Actions**. A publicação pode levar alguns minutos após o commit.
- Para desenvolvimento, clone o repositório e use commits. O editor compartilhado se atualiza por `public/data/edicoes.json`. Confira a seção de sincronização do README.

[Editor publicado](https://gustavomissawa.github.io/antropologo-rpg-map/)
